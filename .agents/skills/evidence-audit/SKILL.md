# Skill: Evidence Audit

## When to use
Before analysis, when a report is blocked/partial, during peer review, or when a material claim is challenged.

## Procedure
1. Confirm symbol, run ID, schema version, and timestamps.
2. Read readiness, source health, evidence quality, reconciliation, then the evidence pack.
3. Inventory material claims and map each to source/calculation/interpretation/assumption.
4. Check period, units, freshness, provenance, and source conflicts.
5. Verify screenshot-derived assertions are not being treated as numeric facts.
6. Produce severity-ranked findings and exact evidence gaps.

## Output
Use the shared agent-result schema. Do not alter source artifacts. A failed readiness gate stays failed.
