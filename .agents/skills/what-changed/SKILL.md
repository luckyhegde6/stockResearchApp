# Skill: What Changed

Compare two completed runs for the same canonical symbol.

1. Confirm run identities and comparable periods.
2. Compare structured fields, not free-text summaries alone.
3. Classify each change: new, removed, increased, decreased, unchanged, unavailable, or incomparable.
4. Attach old/new values, units, period/as-of, source references, and quality/freshness changes.
5. Assess materiality with an explicit rule; do not imply causality.
6. Explain whether the thesis changed and why.
7. Flag non-comparable periods; do not manufacture deltas.

Return a structured diff with evidence links and caveats.
