# Skill: Valuation Scenarios

1. State the valuation model and why it fits available evidence.
2. List sourced inputs, periods, units, and provenance.
3. List analyst assumptions separately, including horizon and growth/margin/multiple assumptions.
4. Calculate outputs deterministically where possible.
5. Run sensitivity analysis on dominant assumptions.
6. State invalidation conditions and missing inputs.
7. Never fabricate consensus estimates or present scenarios as guarantees.
