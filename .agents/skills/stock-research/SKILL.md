# Skill: Stock Research

1. Resolve the symbol through the existing NSE workflow.
2. Run deterministic research using the documented CLI.
3. Inspect readiness before any optional analysis.
4. Use canonical evidence and explicit calculations only.
5. Organize output: executive view; market/price action; earnings/financials; fundamentals/valuation; technicals; news/catalysts; findings/risks; sources/quality; screenshots.
6. Include scenarios only when assumptions and inputs are explicit.
7. Include counter-evidence, missing inputs, and what would change the view.
8. Validate schema and readiness; report partial/blocked status honestly.

Never invent values, imply real-time prices without timestamps, suppress conflicts, or treat model fluency as confidence.
