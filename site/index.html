Stock Research Pipeline

A deterministic, NSE-first pipeline that produces traceable stock-research evidence, validates readiness, and optionally generates a schema-validated final analysis.

1. Acquire

Collect exchange, fundamentals, ownership, market, chart, and news evidence from defined sources.

2. Normalize

Preserve raw artifacts and convert supported documents into Markdown evidence for review.

3. Analyze

Use the prepared evidence package for optional LLM reasoning with a validated JSON contract.

Run npm run research -- ITC to prepare an evidence package. Configure the optional LLM variables in .env before running npm run analyze -- ITC.
