# v1.37 Operating Guide

## 1. Long-lived market scans

Run:

```cmd
npm run chartink:scans -- all
npm run nse:52week-high
npm run scan:quality
```

Each run creates a date-stamped directory under `scans/`. Never mix the dated market archive with `research/<TICKER>/`.

## 2. Chartink categories

`config/chartink-market-scans.json` and `src/lib/chartink-scan-registry.ts` are the scan constants. Acquisition is CSV-first, Copy → Table → OK fallback, then visible-table fallback. The registry classification is authoritative.

`MomentumHourlyBearish_AmitB` and `MomentumDailyBearish_AmitB` are classified as Bearish because their scan names are explicitly bearish.

## 3. Market-scan quality

`npm run scan:quality` validates:

- registry URL uniqueness and validity
- configured vs completed scans
- per-scan non-zero/empty-result semantics
- real CSV file presence and byte count
- normalized symbol coverage against `EQUITY_L.csv`
- NSE 52-week-high rows and EQ membership
- TradingView screenshot existence
- candlestick-selection verification for candlestick claims

A zero-row scan is never marked complete. Empty result sets may be legitimate, but they are represented as `partial` until the source-level result state is explicitly evidenced.

## 4. Individual stock research

```cmd
npm run analyze -- ITC
```

The command runs the deterministic acquisition and preparation pipeline automatically. BSE is excluded. The individual evidence package is written to `research/ITC/normalized/`.

## 5. Individual stock outputs

```text
research/<TICKER>/normalized/
├── identity.json
├── market.json
├── financials.json
├── ownership.json
├── technicals.json
├── screening.json
├── catalysts.json
├── screener-financial-tables.json
├── tijori-context.json
├── canonical-values.json
├── reconciliation.json
├── individual-stock-evidence.json
└── analysis-inputs.json
```

## 6. Evidence precedence

Identity and exchange security metadata come from the NSE securities master. Current market facts and historical OHLCV come from NSE. Numeric technical indicators are deterministically calculated from NSE EQ history. TradingView is independent visual/audit evidence. Chartink is point-in-time screening evidence. Screener and Tijori are cross-check sources for fundamentals and business/financial context.

## 7. Troubleshooting

Use:

```cmd
npm run debug:show -- ITC
npm run tradingview-doctor -- ITC
npm run test:individual-stock-evidence -- ITC
npm run test:market-scan-quality
```

No LLM is used by these commands.
