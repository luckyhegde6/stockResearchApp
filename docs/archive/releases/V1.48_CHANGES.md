# v1.48 — News & Market Sentiment

Adds a deterministic news/sentiment evidence layer and a TradingView structured symbol snapshot.

## Deterministic sources
- TradingView News Flow, filtered to `NSE:<SYMBOL>`.
- Google News RSS as a broad discovery cross-check.
- NSE corporate announcements already captured during core NSE acquisition.
- TradingView scanner symbol snapshot using the configured field list.

## No LLM
All news acquisition, normalization and headline sentiment scoring happen before the LLM boundary.

## Analysis contract
The analysis evidence pack and `analysis-inputs.json` expose `newsSentiment` and the TradingView symbol snapshot. The final JSON schema now has a `news_sentiment` section.

## Readiness
News is supplementary and never blocks readiness. Missing news reduces context richness rather than pretending the sentiment is neutral.
