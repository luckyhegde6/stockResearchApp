# v1.43 — Canonical NSE NextApi Instrument Data

## Purpose

Replace the legacy `/api/quote-equity` route as the normal individual-stock quote path with NSE's NextApi `GetQuoteApi` routes, and preserve richer instrument evidence.

## Canonical endpoints

For a target `SYMBOL`:

```text
/api/NextApi/apiClient/GetQuoteApi?functionName=getSymbolName&symbol=SYMBOL
/api/NextApi/apiClient/GetQuoteApi?functionName=getMetaData&symbol=SYMBOL
/api/NextApi/apiClient/GetQuoteApi?functionName=getSymbolData&marketType=N&series=EQ&symbol=SYMBOL
```

After `getSymbolData` resolves `identifier` (for ITC: `ITCEQN`):

```text
/api/NextApi/apiClient/GetQuoteApi?functionName=getYearwiseData&symbol=IDENTIFIER
/api/NextApi/apiClient/GetQuoteApi?functionName=getSymbolChartData&symbol=IDENTIFIER&days=1D
```

## Quote semantics

`GetQuoteApi/getSymbolData` is the primary source. The previous `/api/quote-equity` endpoint is not called by the normal research flow.

For the supplied ITC response:

- `lastPrice` comes from `tradeInfo.lastPrice`, with `orderBook.lastPrice` and `metaData.closePrice` as deterministic fallbacks.
- `previousClose` comes from `metaData.previousClose`, then `basePrice`.
- OHLC and change fields come from `metaData`.
- traded volume/value, delivery, FFMC and total market cap come from `tradeInfo`.
- 52-week high/low and dates come from `priceInfo`.
- sector, macro, industry, primary index and full index list come from `secInfo`.

## Yearwise performance

The yearwise response is normalized into rows such as:

```json
{
  "period": "one_year",
  "stockChangePct": -37.64,
  "indexChangePct": -1.42,
  "referenceDate": "24-AUG-26",
  "indexName": "NIFTY 50"
}
```

This is source-derived, not calculated by the LLM.

## 1D chart data

The raw `grapthData` array is preserved and normalized into timestamp/price/change records. It is supplementary intraday evidence; it does not replace the canonical NSE daily OHLCV history or TradingView screenshots.

## Deterministic boundary

All five endpoints are acquired and normalized without an LLM. The final model receives their canonical values through the evidence contract and analysis inputs.
