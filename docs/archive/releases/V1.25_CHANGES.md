# v1.25.1 Changes

1. TradingView stock charts now target the direct Supercharts URL on `in.tradingview.com`.
2. Added bounded 5Y and All visual chart captures per ticker.
3. Added best-effort Candles/Candlestick selection.
4. Added detailed range/candlestick capture metadata.
5. Tijori same-page capture no longer calls `page.goto('')`.
6. Tijori load-more growth detection now checks both DOM link count and body-text growth.
7. Tijori remains bounded by maximum iterations and stagnation detection.
8. Chartink remains included and isolated from TradingView/Tijori changes.

9. Tijori quarterly results now use body-text card parsing as a deterministic supplement to table parsing.
10. Prevented empty-string navigation during same-page captures.
