# v1.14 Source Validation

The full research command now performs deterministic validation after acquisition and before MarkItDown/LLM analysis.

## Outputs

`research/<TICKER>/source-health.json`

Per-source operational status, artifact counts, gaps, warnings, fallback counts, and warning details.

`research/<TICKER>/evidence-quality.json`

Field/content presence checks for expected evidence from NSE, BSE, Screener, Tijori, and TradingView.

`research/<TICKER>/raw/tradingview/technical-normalized.json`

Deterministic EMA50, EMA200, RSI14 and latest OHLCV derived from the canonical NSE EQ dataset. This does not replace TradingView; it gives the final analysis a machine-readable technical baseline and allows comparison with TradingView evidence.

## CLI checks

```cmd
npm run source:health -- RELIANCE
npm run evidence:quality -- RELIANCE
npm run quality -- RELIANCE
```

All three are deterministic and do not call an LLM.
