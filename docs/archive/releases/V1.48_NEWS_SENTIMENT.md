# v1.48 — News & Market Sentiment

Adds deterministic company-news acquisition and headline sentiment to the symbol-agnostic stock evidence engine.

## Sources
- TradingView News Flow: symbol-filtered `NSE:<SYMBOL>` endpoint with cursor pagination.
- Google News RSS: company/ticker query cross-check, headline metadata only.
- NSE corporate announcements: reused from the already-acquired NSE NextApi response.
- TradingView symbol scanner: point-in-time structured values from `scanner.tradingview.com/symbol`.

## Sentiment policy
Sentiment is deterministic headline-level polarity with recency weighting. It is not article-body sentiment and is not an investment recommendation. Missing feeds reduce evidence richness but do not block analysis.

## Storage
`research/<SYMBOL>/raw/news/`
`research/<SYMBOL>/normalized/news-sentiment.json`
`research/<SYMBOL>/raw/tradingview/symbol-scanner.json`
`research/<SYMBOL>/raw/tradingview/symbol-scanner-normalized.json`

## Commands
`npm run research:news -- SYMBOL`
`npm run analyze -- SYMBOL`
