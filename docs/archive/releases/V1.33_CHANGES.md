# v1.33 — Analysis Orchestration & NSE-First Evidence Boundary

## Core behavior
`npm run analyze -- TICKER` now orchestrates:
1. deterministic research/acquisition
2. deterministic analysis preparation
3. deterministic readiness gate
4. final LLM reasoning only if ready

## BSE
BSE is excluded from the production source list and readiness requirements. NSE is the primary exchange source.

## Advisory gaps
Known NSE annual-report discovery gaps are advisory and do not block the LLM handoff. Core missing evidence still blocks.

## Preparation ordering
The final analysis prompt is generated before readiness evaluation. `analysis-prep.json` is written after readiness, so no circular readiness requirement exists.

## MarkItDown
CSV is accepted by deterministic ingestion. Screenshots are retained as visual evidence inventory; no pixel-derived numbers are invented.

## Validation
- TypeScript transpile/syntax checked.
- TradingView URL and NSE transformer regression tests remain available.
