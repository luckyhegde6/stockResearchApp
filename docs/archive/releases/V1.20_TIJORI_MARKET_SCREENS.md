# v1.20 — Tijori Market-Wide Results, Events & Sector/Macro Capture

This release adds deterministic, LLM-free collection of three public Tijori datasets:

- Latest Quarterly Results: https://www.tijorifinance.com/results/quarterly-results/
- Upcoming Corporate Events: https://www.tijorifinance.com/results/upcoming-events/
- Macro / Ideas Dashboard: https://www.tijorifinance.com/in/macro/

## Acquisition rules

- Public pages only.
- No login automation.
- No premium/export action.
- Playwright Library is used directly by the application.
- First-party page/network evidence is archived.
- Quarterly/upcoming pages support public pagination when exposed.
- Macro captures dashboard text, headings, links and visible company→sector context for later sector analysis.
- No LLM is used.
