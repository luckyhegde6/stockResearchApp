# v1.39 Release — Analysis Evidence Pack

This release moves the project from canonical evidence files into a single deterministic analysis hand-off object.

## New outputs

```text
research/<TICKER>/normalized/analysis-evidence-pack.json
research/<TICKER>/markdown/ANALYSIS_EVIDENCE_PACK.md
```

## Commands

```cmd
npm run evidence:pack -- ITC
npm run prepare:analysis -- ITC
npm run analyze -- ITC
```

`analyze` remains the single end-to-end command. The final LLM call is performed only after deterministic readiness passes.
