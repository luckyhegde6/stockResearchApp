# v1.42 — Individual Stock Evidence Hardening

This release fixes false-negative completeness and readiness behavior observed on the ITC end-to-end run.

## Key fixes
- Screener extraction has more robust table/text fallbacks for valuation and fundamentals.
- NSE shareholding extraction handles nested API containers and semantic percentage/share fields.
- NSE corporate announcements and corporate actions are flattened from nested API containers before catalyst normalization.
- Evidence-quality core checks are based on populated canonical values, not only object existence.
- Readiness supports alternative source paths and exposes exact missing files/groups.
- NSE quote/trade-info HTTP 403 messages are informational when GetQuoteApi fallback is present.
- Analysis inputs expose per-domain counts and completeness.
- `npm run analyze -- TICKER` remains the single end-to-end command and emits detailed readiness diagnostics if the gate blocks.
- BSE remains excluded from production analysis.
- No LLM is used before the final reasoning boundary.
