# v1.48 — News, Market Sentiment & TradingView Symbol Snapshot

This release adds a supplementary deterministic news/sentiment layer to the symbol-agnostic individual-stock engine.

## Added
- TradingView News Flow adapter with bounded cursor pagination.
- Google News RSS discovery cross-check.
- NSE corporate-announcement reuse.
- Deterministic headline sentiment with recency weighting and theme detection.
- TradingView structured symbol-scanner snapshot using the configured field set.
- News and TradingView snapshot added to analysis-inputs and analysis-evidence-pack.
- `news_sentiment` added to the final JSON contract.
- News documented as supplementary and non-blocking.

## Commands
- `npm run research:news -- BEL`
- `npm run test:news-sentiment`
- `npm run analyze -- BEL`
