# v1.49 — TradingView UI Evidence

Adds symbol-agnostic Playwright capture of TradingView stock research surfaces opened through the chart's **More** menu.

Default surfaces:
- Forecast
- News
- Documents
- Seasonals
- Community

Optional surfaces can be configured with `TRADINGVIEW_UI_SURFACES`, e.g.
`TRADINGVIEW_UI_SURFACES=forecast,news,documents,seasonals,community,financials`.

For every surface the adapter:
1. opens the dynamically generated `https://in.tradingview.com/chart/?symbol=NSE:<SYMBOL>` URL;
2. opens **More**;
3. selects the requested surface;
4. waits for the SPA surface to settle;
5. captures a screenshot;
6. captures visible text/state for audit;
7. records success/partial status.

Artifacts are written under:
`research/<SYMBOL>/raw/tradingview/ui-<surface>.json`
and
`research/<SYMBOL>/screenshots/tradingview-<surface>.png`.

The UI screenshots are visual/audit evidence. They do not replace deterministic market, fundamental, or technical values from structured sources.
