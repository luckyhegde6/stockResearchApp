# v1.32 Next Phase — NSE-first deterministic boundary

## Policy
BSE is ignored completely. NSE is sufficient for exchange, filing, market and technical evidence for this application.

## Fixes
- Full acquisition no longer invokes BSE.
- Evidence quality has no BSE checks.
- Source health has no BSE source entry.
- Canonical extraction has no BSE facts.
- Evidence bundle/prompt do not depend on BSE.
- `prepare-analysis` automatically runs deterministic acquisition when `manifest.json` is absent.
- `analyze` calls deterministic preparation before reading the manifest and before the LLM boundary.

## Analysis phase
The pipeline now proceeds through canonical extraction, cross-source reconciliation, MarkItDown ingestion, evidence contract, analysis inputs and readiness before the LLM.
