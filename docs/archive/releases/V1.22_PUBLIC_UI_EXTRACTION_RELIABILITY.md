# v1.22 — Public UI Extraction Reliability

This release fixes the two market-wide acquisition paths that still reported false success or incomplete data.

## Chartink

The acquisition order is now:

1. Open public strategy page.
2. If the stock table is empty, click **Run Scan** and wait for rows/network completion.
3. Click **Copy**.
4. Select **Table** (never Symbols).
5. Wait for the **All pages table data copied successfully** confirmation.
6. Click **OK**.
7. Capture clipboard text through a page-level clipboard-write interceptor with OS clipboard read as fallback.
8. Click **CSV** and capture the actual browser download; a matching CSV network response is a fallback.
9. Validate actual file bytes before marking CSV capture successful.
10. Parse the copied table / visible table into normalized rows.

Every strategy gets a fresh page while the browser context remains shared. One closed/failed page therefore does not terminate all remaining strategies.

### Chartink evidence

Per strategy, the collector records:

- copy attempted
- table option selected
- confirmation detected
- OK clicked
- clipboard characters
- CSV attempted
- CSV bytes
- CSV capture method
- visible row count
- normalized row count
- result source

A strategy with zero normalized rows is **not** silently marked fully successful when the page had visible results or no usable evidence was captured.

## Tijori

### Quarterly results

The public page is a dynamic **Show More** dataset. v1.22 repeatedly:

- captures the currently rendered company result cards;
- clicks Show More / Load More when available;
- waits for the number of company links to increase;
- retains every captured batch;
- deduplicates by company/ticker/date/href;
- preserves the actual quarterly metric table inside each company card.

The live public page currently exposes a `Showing 20 of ...` indicator followed by `Show More`, so ordinary URL pagination is not treated as the primary mechanism. 

### Upcoming events

The adapter extracts company/event rows and will use dynamic load-more or conventional next-page controls when exposed.

### Ideas Dashboard / sector intelligence

The macro collector now uses the actual Ideas Dashboard URL:

`https://www.tijorifinance.com/ideas-dashboard/`

The old `/in/macro/` URL is no longer used as the primary acquisition endpoint because it can redirect into the broader dashboard shell.

Ideas are grouped by visible dashboard category (for example Promoter Buying, Rating Upgrades, Capex Announcement, Margin Expansion, Deleveraging, Coffee Can and Whales Buying) with company, ticker, sector/context where exposed.

## Data-quality rule

A dataset with zero usable rows is never reported as `complete`.

It is classified as `partial` or `error` with an explicit reason.

All collection remains deterministic and `llmUsed=false`.
