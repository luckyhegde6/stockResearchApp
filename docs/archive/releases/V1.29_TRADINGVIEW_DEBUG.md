## Dedicated doctor command

Run:

```cmd
npm run tradingview-doctor -- ITC
```

This creates/resets `research/ITC`, runs only the TradingView adapter, and prints the requested URL, output screenshots, and any warnings.

## Control diagnostics

`debug-state-open-chart.json` records the requested instrument, actual URL, page title, body text sample and the discovered button/menu/aria-label/title controls. This lets the next debugging pass determine whether TradingView exposed `Candles`, `5Y`, and `All` under different labels.

## Preparation order

Do not run `npm run prepare:analysis -- ITC` before the research acquisition has created `research/ITC/manifest.json`.

Use:

```cmd
npm run research -- ITC
```

or, for TradingView-only diagnostics:

```cmd
npm run tradingview-doctor -- ITC
```
