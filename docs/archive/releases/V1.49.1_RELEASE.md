# v1.49.1 — TradingView UI Launcher Hotfix

## Problem
The TradingView stock chart UI in the supplied screenshots does not expose the stock-surface navigation as a text `More` button. The visible control is the four-square/grid launcher in the stock details card on the right. The previous adapter clicked nothing and captured the same chart screenshot for Forecast/News/Documents/Seasonals/Community.

## Fix
The adapter now:
1. Tries semantic/text More controls for older layouts.
2. Detects the active stock card ticker/company in the right sidebar.
3. Finds compact icon buttons immediately to the right of that stock-card label.
4. Uses the first icon in the grid → edit → overflow ordering as the sidebar surface launcher.
5. Writes `raw/tradingview/debug-ui-<surface>-launcher.json` for each surface.
6. Opens the requested surface and verifies the destination/content before marking the artifact `ok`.

## Evidence
The current TradingView UI shown in project screenshots presents: Fundamentals → Financials/Documents, Analysis → Technicals/Seasonals/News/Forecast/Community, and Assets → Options/ETFs/Bonds via the four-square launcher.

## Test
Run `npm run test:tradingview-ui-launcher` and then `npm run tradingview:ui -- ITC`.


## Superseded by v1.49.2
The current TradingView launcher is labeled `Metrics` (tooltip), not `More`. v1.49.2 replaces the More-centric selector with Metrics-first detection and a direct News control fallback.
