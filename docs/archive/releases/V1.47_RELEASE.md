# v1.47 — Investment Reasoning Contract

This release moves the project from deterministic evidence preparation into the final institutional investment-reasoning boundary.

## Highlights

- New investment-reasoning skill and execution prompt.
- Explicit separation of source facts, deterministic calculations and analyst judgments.
- Mandatory evidence audit before recommendation.
- Business, financial, management, valuation, technical, ownership, catalyst, risk, peer and contrarian analysis sequence.
- Confidence vs conviction distinction.
- Evidence-reference convention for material JSON narrative claims.
- Optional Screener/Tijori concall fetch failures are advisory when core stock evidence is complete.
- BSE remains excluded.
- Chartink remains optional for individual stock research.

## Final command

```cmd
npm run analyze -- SYMBOL
```

The command should perform acquisition, deterministic preparation, readiness validation and then the only LLM call.
