# v1.35 — NSE Securities Master & Individual-Stock Routing

## Why
Use the official NSE Equity segment security master as the deterministic source of valid equity symbols, company names, ISINs and series. This prevents navigation words from the live market page being mistaken for tickers and gives the application a reliable query-validation/autocomplete foundation.

## Source
Official NSE page: https://www.nseindia.com/static/market-data/securities-available-for-trading
Official CSV: https://nsearchives.nseindia.com/content/equities/EQUITY_L.csv

The supplied snapshot contains 2,559 records: EQ 2,287; BE 244; BZ 28.

## New files
- `data/EQUITY_L.csv` — preserved source snapshot
- `data/EQUITY_L.sha256` — snapshot checksum
- `data/nse-equity-universe.json` — deterministic normalized security master
- `data/nse-equity-universe.meta.json` — provenance/count metadata
- `src/lib/nse-securities.ts` — parser/resolver
- `scripts/refresh-nse-securities.ts` — official-source refresh
- `scripts/nse-security-cli.ts` — CLI lookup helper
- `scripts/test-nse-securities.ts` — regression test

## Individual stock routing

`research` and `analyze` now resolve the user query through the NSE security master. Exact symbols and exact company names are supported. Unknown input returns deterministic suggestions rather than being passed to source adapters.

Individual stock research requires series `EQ`. BE/BZ are retained in the master for validation/context but are not treated as normal stock-research instruments.

## Important separation

Market-wide datasets remain outside `research/<TICKER>/`: Chartink top-20 lists, Screener market screens, Tijori market datasets, and NSE index universes are reusable context. Individual ticker research only stores target-specific evidence and membership references.
