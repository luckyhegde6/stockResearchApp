# v1.27 — NSE Market Universe DTO & Normalization

## Changes
- Added typed DTOs for `getIndicesData` rows, index datasets, market status, quote datasets, and index membership.
- Added deterministic transformer layer for the real response shape: `payload.data.data[]`.
- Added a complete 122-entry NSE index catalog supplied for this release, with display name -> API symbol mapping and category.
- `getIndexList` is preserved raw and normalized; the supplied catalog is retained as the stable acquisition plan and fallback.
- Every catalog index is fetched using its API symbol, not its display label.
- NIFTY 50 / NIFTY 500 are explicitly included by the catalog and receive dedicated symbol-list files.
- Market-wide quote universe is built from validated index constituents plus live-equity-page symbols; target ticker is prioritized first for smoke tests.
- Quote normalization now recursively finds the actual `symbol` + price object, avoiding the prior `lastPrice=null` false-success state.
- Live-equity-page scraping no longer treats arbitrary uppercase link text as a security symbol.
- Zero-row / incomplete quote or index payloads are reported as partial/warn, never successful complete data.
- Added a deterministic transformer smoke test using the supplied NIFTY 50 sample payload.

## Commands
```cmd
npm run test:nse-market-transformers
set NSE_MARKET_MAX_SYMBOLS=20
npm run research:nse-market -- ITC
```

For the full market universe:
```cmd
set NSE_MARKET_MAX_SYMBOLS=0
npm run research:nse-market -- ITC
```

## Output
`research/market-screens/nse/indices/` contains raw API responses, normalized DTO datasets, the full index catalog, and consolidated symbol lists.
`research/market-screens/nse/equities/` contains one raw + normalized JSON artifact per fetched symbol.
