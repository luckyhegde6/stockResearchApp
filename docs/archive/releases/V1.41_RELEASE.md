# v1.41 — Final Individual-Stock Evidence Completeness

The company-level deterministic evidence package is now period-aware and domain-complete before final LLM reasoning.

## Core domains
- Identity: NSE EQUITY_L security master.
- Market: NSE quote/fallback facts and stored 52-week-high context.
- Fundamentals: NSE results plus Screener/Tijori actual values.
- Financial periods: period-aware NSE result rows and Screener tables.
- Valuation: PE, market cap, book value, dividend yield and related values when exposed.
- Ownership: promoter/FII/DII/public/pledge/share-count values when exposed from the NSE shareholding payload.
- Technicals: deterministic EMA50, EMA200, RSI14, close and volume plus TradingView 1D/5Y/All visual evidence.
- Screening: Chartink strategy membership, dated market screens and NSE 52-week-high membership.
- Catalysts: NSE announcements/corporate actions and any available Tijori market signals.

## Quality semantics
A scanner returning no results is a valid state, not a data gap. BSE remains excluded from production evidence. Missing core individual-stock domains remain blocking; advisory source conditions do not manufacture missing values.

## LLM boundary
Acquisition, normalization, reconciliation, MarkItDown ingestion, evidence contract and readiness remain deterministic. The final analysis model receives the canonical `normalized/analysis-inputs.json` package.
