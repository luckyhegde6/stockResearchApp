# v1.46 Release Notes

## Symbol-agnostic stock research
Input is normalized before NSE security-master resolution. This supports bare NSE symbols, NSE-prefixed symbols, `.NS` symbols and TradingView URLs.

## Minimal-by-default source policy
Individual stock analysis uses NSE, Screener, Tijori and TradingView by default.
Set `RESEARCH_INCLUDE_CHARTINK=true` to add Chartink stock-level strategy membership.

Market-wide Chartink scans remain separate and are not controlled by the stock-level flag.

## Segregated diagnostics
Each research run writes:
- `run-context.json`
- `debug/acquisition-debug.json`
- `debug/acquisition-debug.jsonl`
- `debug/acquisition-timeline.txt`
- `debug/artifact-index.json`
- `debug/sources/<source>/summary.json`

## Evidence-quality changes
Chartink checks are `not_applicable` when disabled. BSE is excluded from production analysis. Empty/no-result scanners remain informational.

## Datewise NSE evidence
The existing NSE NextApi snapshot index remains under `research/<SYMBOL>/snapshots/YYYY-MM-DD/`.
