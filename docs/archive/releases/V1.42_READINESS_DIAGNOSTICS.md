# v1.42 Readiness Diagnostics

`analysis-readiness.json` now exposes:

- `missingFiles`
- `missingFilesByGroup`
- `alternativeRequiredFiles`
- `coreCompleteness`
- `actionableWarnings`

The readiness gate does not treat NSE quote 403 messages as actionable when a deterministic GetQuoteApi fallback produced the quote.

The readiness gate does not require a single physical raw-file layout when an equivalent normalized evidence artifact exists.
