# v1.49.5 — TradingView Direct Public Symbol-Page Surfaces

TradingView Forecast, News, Documents, and Seasonals (plus Community) are now captured directly by Playwright from the public symbol-page routes instead of clicking the Metrics launcher.

## Routes

For an NSE symbol such as ITC:

- `/symbols/NSE-ITC/news/`
- `/symbols/NSE-ITC/documents/`
- `/symbols/NSE-ITC/seasonals/`
- `/symbols/NSE-ITC/forecast-price-target/`
- `/symbols/NSE-ITC/community/`

The symbol is constructed dynamically for every ticker.

## Capture contract

For each configured surface the adapter:

1. builds the public route from the resolved ticker;
2. navigates to it with Playwright;
3. waits for the SPA/content to settle;
4. validates the expected route/content signature;
5. captures a **full-page screenshot**;
6. stores the surface JSON with route, confirmation, screenshot and body-text evidence.

The Metrics launcher is no longer required for these surfaces.

## Why

The TradingView chart UI changes its internal launcher structure frequently. The public symbol-page routes are simpler, explicit destinations and match the screens shown in the research workflow.
