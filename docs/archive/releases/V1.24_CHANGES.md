# v1.24 — Chartink CSV-First Acquisition

## Chartink strategy acquisition

The strategy collector now uses a strict extraction order:

1. Open the public strategy page.
2. Confirm the visible scanner result table is populated (run scan only if necessary).
3. Attempt the **CSV** button first.
4. Treat CSV as successful only after an actual non-empty file is saved and parsed into stock rows.
5. If CSV is unavailable, times out, produces no file, or produces no parseable rows, use **Copy → Table → OK** as the fallback.
6. If Copy is also unusable, use the visible DOM table and then `/screener/process` only as deterministic lower-level fallbacks.

## Reliability fixes

- CSV download timeout/rejection is contained with an immediately-attached rejection handler; it cannot crash the whole run.
- A CSV timeout is not retried indefinitely.
- Copy is not attempted when CSV produced usable rows.
- A strategy gets its own Playwright page.
- `csvCaptured=true` is emitted only for a verified non-empty saved file.
- CSV file contents are parsed and become the preferred normalized source (`resultSource=csv-download`).
- Debug logs record CSV method/bytes and whether the Copy fallback was invoked.
