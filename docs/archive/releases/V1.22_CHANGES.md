# v1.22 Changes

- Chartink Copy -> Table -> OK is now the primary result acquisition path.
- Added page-level clipboard interception so the application does not depend solely on the Windows clipboard.
- Added explicit Copy confirmation detection.
- Added real CSV download capture and byte-size validation.
- Added Run Scan recovery when a Chartink public strategy opens with an empty result table.
- Kept one fresh Playwright page per Chartink strategy while preserving a shared browser context.
- Prevented zero-row Chartink strategies from being treated as unconditionally successful.
- Fixed Chartink debug fields for Copy, CSV and result completeness.
- Reworked Tijori quarterly parsing around company result cards and their embedded quarterly metric tables.
- Added dynamic Show More / Load More collection for Tijori quarterly results.
- Improved Tijori upcoming-event extraction with dynamic pagination detection.
- Switched Tijori market-intelligence acquisition to the Ideas Dashboard rather than relying on /in/macro/ redirection.
- Added category-aware Tijori Ideas Dashboard extraction.
- Added explicit data-gap handling when a market dataset produces zero usable rows.
- Preserved the deterministic, LLM-free acquisition boundary.
