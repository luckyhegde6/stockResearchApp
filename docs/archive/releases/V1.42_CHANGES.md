# v1.42 — Individual Stock Evidence Hardening

## Purpose
Harden the individual-stock evidence layer so the final analysis handoff is based on actual structured values and explicit readiness diagnostics.

## Changes
- Expanded Screener scalar extraction and text fallback for valuation/fundamental cards.
- Added nested-container handling for NSE shareholding and announcement/corporate-action payloads.
- Strengthened catalyst extraction from nested NSE API response shapes.
- Tightened evidence-quality core checks around actual populated values rather than object existence.
- Added domain counts to normalized analysis inputs.
- Added readiness missing-file grouping and diagnostic output.
- NSE quote 403 fallback warnings remain informational when GetQuoteApi recovered the quote.
- No BSE dependency is introduced.
- No LLM is used by acquisition, normalization, quality or reconciliation.
