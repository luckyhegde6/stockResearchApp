# v1.38 — Canonical Evidence Reconciliation

## Purpose
Freeze acquisition and improve deterministic individual-stock evidence quality before the final LLM reasoning boundary.

## Changes
- Added explicit source-precedence rules for identity, market, valuation, financials, ownership, technicals, screening and catalysts.
- Improved NSE quote extraction by resolving the target symbol record before reading price fields and supporting wrapped numeric values.
- Added `normalized/financial-periods.json` preserving NSE result rows and Screener period tables.
- Expanded individual-stock screening context with latest long-lived market scans and Tijori market signals.
- Added deterministic reconciliation with resolved source when values agree and explicit unresolved material conflicts when they do not.
- Added analysis-input fields and rules that explicitly exclude BSE from production evidence.
- Added 52-week-high quality semantics so unmatched security-master rows are advisory rather than an automatic hard failure.
- Added source-precedence regression test.

## LLM boundary
No LLM is used by acquisition, normalization, reconciliation, quality validation or analysis preparation.
- Removed BSE extraction from the evidence contract itself; BSE is outside the production source model.
- Added dated-directory selection for latest market-scan and 52-week-high evidence instead of lexical-only ordering.
- Added market-scan quality summary to analysis inputs.
