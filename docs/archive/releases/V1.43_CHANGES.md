# v1.43 Changes

## Canonical NSE NextApi instrument acquisition

The individual-stock NSE adapter now uses these NextApi endpoints as the normal route:

- `getSymbolName?symbol=<SYMBOL>`
- `getMetaData?symbol=<SYMBOL>`
- `getSymbolData?marketType=N&series=EQ&symbol=<SYMBOL>`
- `getYearwiseData?symbol=<IDENTIFIER>`
- `getSymbolChartData?symbol=<IDENTIFIER>&days=1D`

The legacy `/api/quote-equity` and `/api/quote-equity?...section=trade_info` routes are retained only as legacy endpoint definitions for backwards compatibility; the normal individual-stock pipeline no longer calls them.

## Rich quote normalization

The supplied ITC response shape is now mapped from the correct nested sections:

- `metaData` — identity, OHLC, close, change
- `tradeInfo` — LTP, volume, turnover, delivery, FFMC, market cap
- `priceInfo` — 52-week high/low and dates, tick size, price band
- `secInfo` — sector, macro, industry, index, full index membership
- `orderBook` — final LTP fallback

This fixes the earlier false `lastPrice=null` normalization.

## Instrument identity and metadata

Raw and normalized `getSymbolName` and `getMetaData` responses are preserved for audit and future query validation.

## Yearwise performance

The resolved NSE security identifier (for ITC, `ITCEQN`) is used for yearwise stock-vs-index performance. Values are source-derived and retain period labels.

## 1D chart data

The `getSymbolChartData` `1D` response is preserved and normalized into timestamp/price/change rows. It is supplementary market evidence and does not replace the daily OHLCV history or TradingView screenshots.

## Evidence integration

Individual-stock canonical evidence now includes the new NSE market fields, yearwise performance, and 1D chart point count/data. The evidence contract also includes these NextApi-derived facts.

## Tests

Added `scripts/test-nse-nextapi.ts` and `npm run test:nse-nextapi` to validate endpoint construction, ITC sample normalization, identifier resolution, yearwise parsing, and chart parsing.

## Deterministic boundary

No LLM is involved in this release. All new acquisition and normalization work is deterministic.
