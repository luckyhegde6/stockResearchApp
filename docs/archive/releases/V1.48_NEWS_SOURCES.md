# v1.48 News Sources

## 1. TradingView News Flow

Primary market-news feed for the stock. The adapter filters to `lang:en` and `symbol:NSE:<SYMBOL>` and follows cursor pagination up to `NEWS_TV_MAX_PAGES`.

It stores headline metadata, provider, article link, publication timestamp, urgency, paywall flag and related symbols. It does not copy article bodies.

TradingView documents News Flow as the platform's financial-news hub and supports filtering by instrument/provider/sector and other dimensions.

## 2. Google News RSS

Broad discovery cross-check using a company/ticker query. Only RSS headline metadata is retained locally. This is a discovery layer, not a primary corporate source.

## 3. NSE Corporate Announcements

These are already acquired from the NSE NextApi and are reused for the sentiment package. They remain the strongest source for company-specific official disclosures.

## Sentiment

The deterministic sentiment result is headline-level only. It uses a small controlled lexicon, recency weighting and source diversity. It should be corroborated with NSE filings and financial evidence before the LLM treats a theme as material.
