# v1.49.1 Expected TradingView UI Debug

For the current TradingView Supercharts layout, the stock details card on the right has a four-square/grid launcher. This launcher opens the Fundamentals / Analysis / Assets menu.

The adapter should log, per UI surface:

- `launcher: "symbol-panel-grid"` or a semantic launcher strategy
- `strategy: "sidebar-grid-geometry"` when geometry fallback is used
- the selected ticker card node coordinates
- nearby icon candidates and the selected icon candidate
- `surfaceClicked=true`
- a destination/content confirmation for the target surface

A screenshot alone is not considered successful navigation. `status=ok` requires both a non-empty screenshot and a confirmed surface selection.
