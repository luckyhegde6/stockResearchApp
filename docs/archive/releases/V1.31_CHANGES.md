# v1.31 — Evidence Ingestion & Deterministic Analysis Boundary

## Fixed
- `prepare-analysis` no longer references an undefined `writeText` symbol.
- Analysis preparation now builds the prompt before the readiness gate.
- Evidence bundle/readiness ordering is deterministic.
- BSE absence is advisory rather than a blocking evidence-quality failure.
- TradingView 5Y/All screenshot evidence is validated by actual file existence.
- TradingView EMA50/EMA200 can be verified from the canonical deterministic technical dataset.
- MarkItDown ingestion now handles CSV and writes `markdown/INGESTION_REPORT.json`.
- Generated aggregate Markdown files are not re-ingested as source documents.
- Nested numeric wrappers in NSE quote/index payloads are resolved deterministically.
- Chartink/TradingView provenance remains source-specific.

## Next-phase foundation
- Canonical source facts remain separate from deterministic calculations.
- Cross-source reconciliation remains deterministic.
- Visual evidence is inventoried separately from textual MarkItDown evidence.
- No LLM is invoked during acquisition, normalization, ingestion, quality or readiness.
