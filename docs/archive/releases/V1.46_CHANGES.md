# v1.46 — Symbol-Agnostic Research + Optional Chartink

## Goals
- Make individual-stock research input symbol agnostic.
- Make source/debug classification easy to inspect.
- Keep individual stock research minimal by default.
- Make Chartink stock-level acquisition opt-in.
- Keep long-lived Chartink market scans independent from ticker research.
- Exclude BSE from production individual-stock research.

## Feature flag
Set in `.env`:

```dotenv
RESEARCH_INCLUDE_CHARTINK=false
```

Default is `false`.

When false, `npm run analyze -- SYMBOL` acquires:
- NSE
- Screener
- Tijori
- TradingView

Chartink remains available through:
```cmd
npm run chartink:scans -- all
```

When true, Chartink is added to the ticker acquisition stage.

## Symbol input normalization
The stock engine accepts:
- `ITC`
- `NSE:ITC`
- `NSE/ITC`
- `ITC.NS`
- TradingView URL containing `symbol=NSE:ITC`

All are resolved against the official NSE `EQUITY_L` security master before acquisition.

## Debug segregation
Each run now records:
- `runId`
- normalized instrument
- feature flags
- per-source summaries under `debug/sources/<source>/summary.json`

Core sources:
`NSE`, `Screener`, `Tijori`, `TradingView`

Optional source:
`Chartink`

Excluded:
`BSE`

## Quality semantics
When Chartink is disabled, Chartink quality checks are `not_applicable`, not warnings or missing evidence.
