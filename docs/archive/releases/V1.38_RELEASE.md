# v1.38 Release — Canonical Evidence Reconciliation

## Scope
This release moves the project from source acquisition into deterministic individual-stock evidence reconciliation.

### Production sources
- NSE
- Screener
- Tijori
- TradingView
- Chartink

BSE remains outside the production analysis model.

## Individual-stock command

```cmd
npm run analyze -- ITC
```

The command is designed to orchestrate acquisition, normalization, reconciliation, MarkItDown ingestion, bundle creation, readiness validation and only then the final LLM call.

## New/expanded evidence files

```text
research/<TICKER>/normalized/
```

## Deterministic precedence

Identity uses the NSE securities master. Market facts prefer NSE. Valuation facts prefer Screener, then Tijori. Financial facts prefer NSE, then Screener/Tijori. Ownership prefers NSE. Technical numeric calculations come from NSE historical data. Chartink is treated as screening evidence and TradingView as visual/audit evidence.

## Conflict behavior

Minor differences below `EVIDENCE_CONFLICT_THRESHOLD_PCT` are resolved by precedence, then freshness. Material conflicts remain unresolved and are explicitly presented to the later reasoning stage.

## 52-week-high behavior

The NSE 52-week-high source timestamp is retained independently from archive date. Security-master mismatches are quality signals and do not automatically invalidate the dataset.
