# v1.44 — NSE NextApi Evidence Surface

v1.44 makes NSE `GetQuoteApi` the reusable canonical source for individual-equity research beyond price/quote.

## Endpoint families

Identity: `getSymbolName`, `getMetaData`\nMarket: `getSymbolData`, `getYearwiseData`, `getSymbolChartData`\nFinancials: `getFinancialResultData`, `getFinancialStatus`\nCorporate: `getCorporateAnnouncementSubject`, `getCorporateAnnouncement`, `getCorpBoardMeeting`, `getCorpAction`, `getCorpEventCalender`\nOwnership: `getShareholdingPattern`\nAnnual reports: `getCorpAnnualReport`\nCompliance: `getCorpBrsr`\nPeers: `getPeerComparisonQuaters`, `getPeerComparisonData`

## Storage

All raw NextApi responses are grouped under:

`research/<SYMBOL>/raw/nse-api/nextapi/<family>/`

The run writes a lightweight datewise pointer under:

`research/<SYMBOL>/snapshots/YYYY-MM-DD/nse-api-index.json`

Raw evidence is not duplicated by the snapshot index.

## Dynamic date range

Corporate announcements default to the previous 184 days through the current date. Override with `NSE_ANNOUNCEMENT_LOOKBACK_DAYS`.

## Annual reports

`getCorpAnnualReport` is the primary index. The latest `NSE_ANNUAL_REPORT_DOWNLOAD_LIMIT` entries default to 5 and are downloaded when direct PDF/ZIP URLs are available. The filing-page collector remains a fallback/audit mechanism.

## No LLM

Acquisition and normalization are deterministic. The only LLM boundary remains the final investment reasoning command.
