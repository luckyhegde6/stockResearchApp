# v1.32 — NSE-First Evidence Contract + Analysis Preparation

## Policy
BSE is intentionally excluded from the production research path. NSE is the primary and sufficient exchange source for this application.

## Fixes
- Full acquisition no longer invokes the BSE adapter.
- BSE checks are removed from evidence quality, source health, canonical extraction and source doctor.
- `prepare-analysis` creates the manifest by running deterministic acquisition when the ticker manifest is absent.
- `analyze` performs deterministic preparation before reading the manifest or crossing the LLM boundary.
- TradingView technical values are correctly classified as `calculated_metric` with `deterministic_calculation`.
- Screener and Tijori common financial fields use shared canonical field names so reconciliation can compare the same concepts.
- Cross-source reconciliation records provenance and never silently resolves disagreements.
- MarkItDown ingestion includes CSV; screenshots remain visual evidence.

## Final pipeline

```text
NSE + Screener + Tijori + TradingView + Chartink
        ↓
raw evidence
        ↓
canonical extraction
        ↓
cross-source reconciliation
        ↓
MarkItDown ingestion
        ↓
evidence contract / bundle
        ↓
analysis readiness
        ↓
LLM only
```
