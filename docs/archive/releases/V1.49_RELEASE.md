# v1.49 — TradingView UI Evidence Surfaces

This release adds symbol-agnostic Playwright capture of TradingView stock-analysis surfaces opened through the chart's More menu.

## Default surfaces
- Forecast
- News
- Documents
- Seasonals
- Community

## Optional surfaces
- financials
- options
- etfs
- bonds

Configure with `TRADINGVIEW_UI_SURFACES=forecast,news,documents,seasonals,community`.

## Dynamic symbol
The chart URL is built from the resolved NSE ticker:
`https://in.tradingview.com/chart/?symbol=NSE:<SYMBOL>`

There is no hard-coded ITC or RELIANCE URL.

## Capture workflow
For each configured surface:
1. Open the dynamic stock chart.
2. Open More.
3. Select the named surface.
4. Wait for SPA rendering.
5. Capture screenshot.
6. Capture visible state/text for debugging.
7. Record confirmation status.

## Outputs
- `research/<SYMBOL>/raw/tradingview/ui-surfaces.json`
- `research/<SYMBOL>/raw/tradingview/ui-<surface>.json`
- `research/<SYMBOL>/screenshots/tradingview-<surface>.png`

## Evidence rules
These screenshots are supplementary visual/audit evidence. They are not numeric truth and do not replace structured NSE/Screener/Tijori/TradingView data.

A UI-surface navigation failure is non-blocking and is recorded as supplementary evidence unavailable/partial. Core TradingView health is calculated independently of `tradingview-ui-*` artifacts.

## Commands
- `npm run tradingview:ui -- ITC`
- `npm run test:tradingview-ui-surfaces`
- `npm run analyze -- ITC`
