# v1.13 Changes

## Data-quality normalization

- Adds `src/lib/data-quality.ts`.
- Generates `research/<TICKER>/raw/nse-api/historical-quality.json`.
- Validates OHLC relationships, chronology, duplicate dates, invalid/missing dates, volume and delivery consistency, final EQ series, and requested date coverage.
- Distinguishes raw duplicate keys from final duplicate dates.
- Keeps `historical-normalized.json` as the canonical deduplicated EQ dataset.

## Debugging

The full research command now creates adapter-level checkpoints in `research/<TICKER>/debug/acquisition-debug.json`, JSONL, and timeline files. The terminal shows `SOURCE/NSE`, `SOURCE/BSE`, `SOURCE/Screener`, `SOURCE/Tijori`, and `SOURCE/TradingView` checkpoints.

## Status semantics

`SourceArtifact.status` now supports `ok_with_fallback` in TypeScript as used by the NSE quote fallback.

## Validation commands

```cmd
npm run research -- RELIANCE
npm run quality -- RELIANCE
```

`npm run quality -- RELIANCE` reads the deterministic historical-quality report and fails with exit code 1 when the dataset has quality errors.
