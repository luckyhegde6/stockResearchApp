# v1.49.2 — TradingView Metrics UI Launcher

## Purpose
Fix TradingView surface capture for the current Supercharts UI.

The supplied UI shows the stock-card launcher with the tooltip **Metrics**, not a text **More** button. The four-square/grid control is the correct primary launcher for Financials, Documents, Technicals, Seasonals, News, Forecast, Community and related surfaces.

## Primary navigation

```text
Dynamic chart URL
  -> locate stock details card
  -> click Metrics (semantic or geometry fallback)
  -> click requested surface
  -> wait for SPA
  -> confirm by route/content
  -> screenshot + debug JSON
```

## News alternate

For `news`, the adapter first attempts an exact right-panel News control, then falls back to `Metrics -> News`.

## Evidence quality

A screenshot existing is not enough for `ok` status. The target surface must be confirmed after navigation. Failed confirmation remains `partial` and the screenshot is retained.

## Debugging

Per-surface diagnostics are written to:

`research/<SYMBOL>/raw/tradingview/debug-ui-<surface>-launcher.json`

The debug record includes semantic/geometry strategy, candidate controls, selected candidate, card geometry, and click result.
