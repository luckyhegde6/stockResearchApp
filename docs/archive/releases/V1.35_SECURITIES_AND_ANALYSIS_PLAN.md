# v1.35 — NSE Equity Universe + Individual-Stock Analysis Plan

## NSE securities master

The official NSE Securities Available for Trading page links the Equity segment CSV. The project preserves a snapshot of that CSV and a normalized JSON constant-style dataset.

Source page: https://www.nseindia.com/static/market-data/securities-available-for-trading
Source CSV: https://nsearchives.nseindia.com/content/equities/EQUITY_L.csv

The supplied snapshot contains 2,559 securities: EQ=2,287, BE=244, BZ=28. EQ is the preferred series for individual stock analysis; BE/BZ remain catalogued but are not accepted by the individual-stock command.

## Commands

`npm run nse:securities`

Prints universe size and series counts.

`npm run nse:lookup -- ITC`

Resolves ticker/company name using the local NSE master.

`npm run nse:validate-symbol -- ITC`

Fails when the query is not a known NSE security or is not EQ.

`npm run refresh:nse-securities`

Refreshes `data/EQUITY_L.csv`, regenerates `data/nse-equity-universe.json` and `data/nse-equity-universe.meta.json` from the official CSV.

`npm run test:nse-securities`

Regression test for universe size and ITC/RELIANCE resolution.

## Individual-stock analysis phase

The final command remains:

`npm run analyze -- ITC`

The orchestrator should execute, in order, without manual intermediate commands:

1. Validate/resolve ITC against the NSE securities master.
2. Acquire NSE company evidence: quote fallback, financial results, corporate announcements/actions, 3-year OHLCV/delivery, annual reports and shareholding.
3. Acquire Screener company fundamentals and period tables.
4. Acquire Tijori company financial/context evidence.
5. Acquire TradingView 1D + 5Y + All candlestick screenshots and technical page.
6. Acquire Chartink strategy CSVs and derive target-symbol membership.
7. Normalize all source facts and period-aware financial tables deterministically.
8. Calculate technical indicators and derived metrics deterministically.
9. Reconcile cross-source values with provenance, as-of timestamps, precedence and conflict records.
10. Run MarkItDown over PDFs/CSV/HTML/document evidence and build section-indexed Markdown.
11. Build evidence-quality, source-health, evidence-contract, evidence-bundle and analysis-inputs.
12. Run a deterministic readiness gate. Known BSE conditions are ignored. Fallbacks are advisory unless evidence is actually absent.
13. Only after the gate passes invoke the LLM with the compact evidence package and analysis prompt.

## LLM boundary

Before the final analysis call, no LLM is used for acquisition, parsing, normalization, reconciliation or evidence-quality decisions.
