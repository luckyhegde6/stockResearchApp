# v1.49.2 — TradingView Metrics Launcher

TradingView Supercharts currently exposes the right-side stock navigation as a four-square button whose tooltip is `Metrics`. The UI surface workflow must not assume a text `More` button.

## Primary workflow

1. Open the dynamic `https://in.tradingview.com/chart/?symbol=NSE:<SYMBOL>` URL.
2. Find the stock-details card in the right sidebar.
3. Prefer an accessible/title/data-tooltip control named `Metrics`.
4. If semantic attributes are absent, identify the four-square grid icon by bounded card geometry and SVG shape/attributes.
5. Click Metrics.
6. Select the requested surface: Forecast, News, Documents, Seasonals, Community, Financials, Options, ETFs, or Bonds.
7. Wait for the TradingView SPA to settle.
8. Confirm the surface by route or distinctive visible content.
9. Capture the screenshot and write a debug JSON containing launcher candidates and selection details.

## News alternate path

News can also be opened directly from the right-hand panel. The adapter attempts an exact News control first for the News surface, then falls back to Metrics → News.

## Quality rule

A non-empty screenshot is not sufficient for `status=ok`. The selected surface must be confirmed. Failed confirmation remains `partial` and the screenshot is retained for audit.

## Debug files

`raw/tradingview/debug-ui-<surface>-launcher.json` records the launcher strategy, candidate controls, selected element/geometry, and click result.
