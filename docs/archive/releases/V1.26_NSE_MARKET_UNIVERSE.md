# v1.26 — NSE Market Universe & One-by-One Equity Acquisition

This release adds a deterministic market-wide NSE collector.

## Sources

- Public live equity market page: `https://www.nseindia.com/market-data/live-equity-market`
- NSE index list: `/api/NextApi/apiClient/marketWatchApi?functionName=getIndexList`
- NSE index constituents/data: `/api/NextApi/apiClient/marketWatchApi?functionName=getIndicesData&symbol=<INDEX>`
- NSE per-symbol quote: `/api/NextApi/apiClient/GetQuoteApi?functionName=getSymbolData&marketType=N&series=EQ&symbol=<SYMBOL>`

## Workflow

1. Playwright opens the live-equity-market page and scrapes equity symbols.
2. The index list API is fetched and preserved verbatim.
3. Every index from the list is fetched sequentially via `getIndicesData`.
4. `NIFTY 50` and `NIFTY 500` are always fetched explicitly, even if the index-list payload does not expose them in the first parsed array.
5. Every discovered equity symbol is fetched one at a time using `GetQuoteApi`.
6. Raw responses and normalized JSON are stored separately.
7. A per-ticker membership file can be written into `research/<TICKER>/raw/nse-market/membership.json`.

No LLM is used.

## Commands

```cmd
npm run research:nse-market
```

Optional ticker membership:

```cmd
npm run research:nse-market -- ITC
```

Full research opt-in:

```cmd
npm run research -- ITC --with-nse-market
```

For a limited smoke test:

```cmd
set NSE_MARKET_MAX_SYMBOLS=20
npm run research:nse-market -- ITC
```

For normal operation, leave `NSE_MARKET_MAX_SYMBOLS=0`.
