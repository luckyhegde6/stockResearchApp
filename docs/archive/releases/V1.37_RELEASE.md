# v1.37 Release

## Market Scan Quality & Individual Stock Evidence

v1.37 is the deterministic evidence hardening release after the market-scan acquisition work. It does not add an LLM step.

### Changes
- Corrected the two `Momentum*Bearish_AmitB` entries to Bearish.
- All registered market scans now support visual TradingView evidence; capture remains bounded by `SCAN_CHART_LIMIT`.
- Added market scan quality validation and `scans/market-scan-quality.json`.
- Added official NSE security-master validation to scan symbols.
- Added source-as-of/freshness metadata to NSE 52-week-high normalized data.
- Added individual stock normalized evidence package and deterministic reconciliation.
- Added compact `normalized/analysis-inputs.json`.
- Extended evidence contract with v1.37 canonical values.
- BSE remains outside the production evidence contract.

## Commands

```cmd
npm run chartink:scans -- all
npm run nse:52week-high
npm run scan:quality
npm run stock:evidence -- ITC
npm run stock:reconcile -- ITC
npm run analyze -- ITC
```

`analyze` is still the single stock-level command. Market scans are intentionally separate and long-lived.
