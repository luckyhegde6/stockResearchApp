# v1.45 Datewise Individual Equity Research

Individual ticker research is intentionally disposable and can be wiped/rebuilt. Datewise evidence is represented by a lightweight index rather than duplicated payloads.

```text
research/<SYMBOL>/
├── raw/
│   └── nse-api/
│       └── nextapi/
├── snapshots/
│   └── YYYY-MM-DD/
│       └── nse-api-index.json
└── nse-api-index.json
```

`nse-api-index.json` points to the latest raw acquisition report. The dated index records the endpoint status, source URL, relative payload path, retrieval time and date range.

The raw JSON remains authoritative. The snapshot index is metadata only and does not duplicate raw response bodies.

## Why this design

- `research/<SYMBOL>/` can be safely rebuilt for a fresh analysis.
- Dated indices preserve a machine-readable audit trail.
- The same endpoint registry can be reused for any symbol.
- No LLM is required for acquisition or snapshot indexing.
