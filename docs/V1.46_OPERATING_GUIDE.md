# v1.46 Operating Guide

## Individual stock research

```cmd
npm run analyze -- COALINDIA
```

This command performs the complete deterministic stock pipeline and only invokes the LLM after readiness passes.

## Minimal source set

By default:
- NSE
- Screener
- Tijori
- TradingView

Chartink is not run for the ticker unless enabled.

## Enable Chartink for individual research

```dotenv
RESEARCH_INCLUDE_CHARTINK=true
```

Then:
```cmd
npm run analyze -- COALINDIA
```

The Chartink strategy evidence is written under the ticker research tree.

## Market-wide scans

Market-wide Chartink scans remain long-lived and separate:

```cmd
npm run chartink:scans -- all
```

NSE 52-week highs:
```cmd
npm run nse:52week-high
```

These write under `scans/`, not `research/<SYMBOL>/`.

## Debug workflow

Inspect:
1. `manifest.json`
2. `acquisition-report.json`
3. `debug/acquisition-debug.json`
4. `debug/acquisition-debug.jsonl`
5. `debug/acquisition-timeline.txt`
6. `debug/sources/*/summary.json`

Each source summary makes it immediately visible whether a source was `ok`, `ok_with_warnings`, `partial`, `error`, or `skipped`.

## Chartink feature flag semantics

`RESEARCH_INCLUDE_CHARTINK=false` means Chartink is excluded from the stock acquisition loop. It does not disable the separate market-wide Chartink scan commands.

When disabled, `normalized/screening.json` remains valid and records the feature as disabled. Evidence quality marks Chartink checks as `not_applicable`.

When enabled, Chartink strategy membership is added to the ticker evidence and all existing CSV-first/no-results behavior remains active.

## Artifact classification

`debug/artifact-index.json` classifies every generated artifact by:
- provider
- core/optional/excluded class
- evidence type
- status
- source method
- period
- relative file paths

This is the quickest machine-readable map for debugging a run.

## Source policy file

`config/research-sources.json` is the single human-readable source-policy declaration:
- core stock sources
- optional stock sources
- excluded sources
- feature-flag name/default
- long-lived market sources

Use it when adding or removing adapters instead of editing individual validators ad hoc.
