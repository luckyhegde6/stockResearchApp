# v1.38 Market Scan Walkthrough

Market-wide scans are long-lived and stored under `scans/`. Individual-stock research is short-lived and stored under `research/<TICKER>/`.

## Chartink

```cmd
npm run chartink:scans -- bullish
npm run chartink:scans -- bearish
npm run chartink:scans -- swing
```

CSV is attempted first. Copy → Table → OK is fallback. Non-empty downloaded files are required before CSV is marked successful.

## NSE 52-week high

```cmd
npm run nse:52week-high
```

The raw API response is preserved, normalized rows include series classification and security-master validation, and source timestamp is retained separately from archive date.

## Quality

```cmd
npm run scan:quality
```

A scan is not considered complete solely because a page loaded. Row counts, CSV evidence, source-master matching and chart evidence are evaluated deterministically.
