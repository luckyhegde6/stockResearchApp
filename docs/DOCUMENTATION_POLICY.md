# Documentation Policy

The repository is intentionally documentation-light.

## Canonical homes

- Behavior → README.md
- Agent/dev rules → AGENTS.md
- Stable memory → MEMORY.md
- Current state → HANDOFF.md
- Backlog → TODO.md
- Decisions → DECISIONS.md
- Product requirements → docs/prd/
- CLI reference → docs/CLI_REFERENCE.md
- Operating workflow → docs/PIPELINE_OPERATING_GUIDE.md
- Deep technical reference → the focused file under docs/
- Releases → CHANGELOG.md

## Avoid

- duplicate agent instructions
- one-off version guides for routine changes
- pasted logs
- generated research snapshots
- vendor-specific rules unless truly required

Superseded material belongs in docs/archive/.
