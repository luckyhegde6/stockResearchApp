What happens when a run is triggered?
The dashboard shows the publishing phase separately from the five research stages. Research and batch runs publish deterministic evidence; analysis publishes the refreshed evidence package and the validated analysis; Laya and market scans publish their generated artifacts. If credentials are missing, the UI shows NOT CONFIGURED. If a pipeline fails before creating an artifact, the sheet step is shown as skipped or failed. Local research outputs remain available if Google Sheets is unavailable.
