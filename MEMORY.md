# Project Memory

Stable facts only. Change this file less often than HANDOFF.md.

## Identity

- Project: Stock Research Pipeline.
- Version: v1.50.0.
- Runtime: Node.js 20+ with TypeScript/tsx.
- Market: NSE India.
- Local dashboard: npm run dashboard → src/server.ts → public/index.html.

## Architecture

~~~text
symbol
  → NSE master resolution
  → source acquisition
  → raw evidence
  → normalization / ingestion
  → canonical evidence
  → reconciliation
  → source health + quality
  → evidence bundle
  → readiness gate
  → optional AI analysis
  → Ajv validation
~~~

## Source policy

Core: NSE, Screener, Tijori, TradingView.
Supplementary: News.
Optional: Chartink via RESEARCH_INCLUDE_CHARTINK=true.
Excluded from production stock research: BSE.

## Contract boundaries

- research/SYMBOL/raw/ is the provenance layer.
- research/SYMBOL/normalized/ is deterministic derived evidence.
- normalized/analysis-evidence-pack.json is the preferred compact reasoning handoff.
- analysis-prompt.txt is assembled from deterministic evidence.
- src/schema.ts is the authoritative analysis output schema.
- Model output is untrusted until validation passes.

## TradingView

Public UI surfaces use direct public symbol-page routes generated by src/lib/tradingview-url.ts.

Configured surfaces:
forecast, news, documents, seasonals, community

Legacy Metrics/More launcher logic is removed.

## Important behavior

- npm run research -- SYMBOL is deterministic acquisition/preparation.
- npm run analyze -- SYMBOL reruns deterministic research before final analysis.
- npm run research:full -- SYMBOL is currently an alias of research.
- research/, outputs/, browser state, scan runtime data, and .env are gitignored.

## Change rules

Preserve public data contracts. Add tests for routing, readiness, schemas, normalization, or source precedence changes. Prefer additive and focused changes.
